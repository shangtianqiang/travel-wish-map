# 旅游心愿地图 — 实施计划

## 已确认的产品决策
- **形式**：Web 网页应用（Vue 3 + Vite + TypeScript + Pinia + Tailwind CSS），手机电脑均可使用
- **点亮机制**：城市 + 景点两级点亮。景点打卡→金色光点；城市内任意景点点亮→城市区域发光并显示进度（如"西安 3/12"）；省内有城市点亮→省界微亮
- **打卡**：手动打卡，支持补录过去日期，可附感想/照片
- **景点三态**：未点亮（暗灰点）→ ⭐心愿（琥珀旗帜）→ 🌟点亮（金色光点+脉冲光晕）
- **数据存储**：本地 IndexedDB（Dexie），所有读写收敛到 async store 层，预留将来接 CloudBase 云同步
- **景点数据**：内置精选数据集（约 60–80 个旅游城市 × 每城 8–15 个景点，含坐标/分类/简介）
- **地图**：Leaflet + 阿里 DataV 行政区划 GeoJSON，深色夜光极简风格，canvas 渲染
- **第一版功能**：地图主页、打卡弹窗、统计看板、心愿清单、打卡日记时间线、点亮海报导出（离屏 canvas 重绘，无截图库依赖）

## 实施步骤

### 步骤 0：文档与工程初始化
- 将已确认设计写入 `docs/superpowers/specs/2026-09-19-travel-wish-map-design.md` 并 git 初始化提交
- Vite + Vue3 + TS 项目脚手架，安装 leaflet、dexie、pinia、tailwindcss

### 步骤 M1：地图底座
- 从 DataV.GeoAtlas 下载全国省级 GeoJSON + 主要城市市级边界，处理打包为静态资源
- Leaflet 深色底图：暗色背景、省界轮廓线、城市边界图层，实现缩放/平移
- 点亮城市区域填充发光效果（canvas renderer）

### 步骤 M2：数据集与点亮机制
- 整理 `cities.json`（60–80 城）与 `attractions.json`（600–800 景点）内置数据
- Dexie store 层（records 表：wish/visit 两类记录，含日期、感想、照片）
- 景点 Marker 三态渲染、打卡弹窗（我想去/打卡/取消）、两级点亮规则与动画

### 步骤 M3：统计看板与心愿清单
- 顶部统计条 + 「我的足迹」统计看板（点亮城市/景点数、省份覆盖、排行榜）
- 心愿清单视图（想去列表、一键转打卡、移除）

### 步骤 M4：打卡日记与海报导出
- 时间线视图（按打卡日期倒序，照片+感想编辑）
- 海报导出：离屏 canvas 重绘点亮地图 + 统计数据卡，下载 PNG

### 步骤 M5：打磨与验收
- 点亮脉冲动画、移动端响应式适配、城市/景点搜索定位
- 浏览器实际走查：打卡→点亮→看板→海报全流程验证

## 验证方式
每步完成后在浏览器中实际操作验证（含移动端视口），最终以完整用户旅程（打开地图→打卡→点亮→查看统计→导出海报）作为验收标准。
