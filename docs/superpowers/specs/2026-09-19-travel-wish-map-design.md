# 旅游心愿地图 — 设计文档

日期：2026-09-19
状态：已与用户确认（方案一：Leaflet + GeoJSON 极简发光风）

## 1. 目标

一个国内旅游足迹可视化 Web 应用：内置全国知名景点数据，用户打卡去过的地方后，
地图上对应景点与城市被"点亮"，形成专属夜光足迹地图，并支持统计、心愿清单、
打卡日记与海报分享。

## 2. 产品决策（用户已确认）

| 决策点 | 结论 |
|--------|------|
| 载体 | Web 网页应用（手机、电脑均可） |
| 点亮粒度 | 城市 + 景点两级点亮 |
| 打卡方式 | 手动打卡，支持补录过去日期，可附感想与照片 |
| 数据存储 | 本地 IndexedDB（先本地），store 层接口 async 化，预留云同步（CloudBase） |
| 景点数据 | 内置精选数据集（约 60–80 旅游城市 × 8–15 景点） |
| 地图方案 | Leaflet + 阿里 DataV 行政区划 GeoJSON，深色夜光极简风格，canvas 渲染 |
| 第一版功能 | 地图主页、打卡弹窗、统计看板、心愿清单、打卡日记、海报导出 |

## 3. 产品设计

### 3.1 页面结构（单页应用，三个视图）

1. **地图主页**（默认）：深色夜光中国地图；顶部统计条（点亮城市数 / 景点数 /
   覆盖省份数）；左下角图例与搜索框。缩放查看全国全貌或城市景点细节。
2. **景点打卡弹窗**：点击景点弹出卡片（名称、简介、分类、当前状态），
   操作：「⭐ 我想去」「🌟 打卡点亮」「取消」。
3. **我的足迹页**：三个 Tab —— 统计看板 / 心愿清单 / 打卡日记。

### 3.2 景点三态与点亮规则

| 状态 | 视觉 | 触发 |
|------|------|------|
| 未点亮 | 暗灰小点 | 默认 |
| 心愿 | 琥珀色旗帜 | 点「我想去」 |
| 点亮 | 金色光点 + 脉冲光晕 | 打卡（可填日期、感想） |

- 城市内任意 1 个景点点亮 → 城市区域发光（市界 GeoJSON 填充 + 光晕），
  并显示进度角标（如「西安 3/12」）。
- 省内有城市点亮 → 省界轮廓微亮。
- 打卡支持补录（填写过去的日期）。

## 4. 数据设计

### 4.1 内置数据集（打包进项目，离线可用）

- `src/data/cities.json`：约 60–80 个主要旅游城市（id、名称、省份、中心坐标、adcode）。
- `src/data/attractions.json`：每城 8–15 个精选知名景点（名称、坐标、分类、简介）。
- `src/data/geo/`：全国省级 GeoJSON + 内置城市的市级边界（DataV.GeoAtlas 下载，
  构建脚本简化坐标控制体积）。

### 4.2 本地数据模型（IndexedDB via Dexie）

单表 `records`，两类记录：

```
records: {
  id: string          // uuid
  attractionId: string
  type: 'wish' | 'visit'
  date?: string       // visit 专有：打卡日期（可补录）
  note?: string       // 感想
  photos?: Blob[]     // 照片（本地版存 IndexedDB；云端版将来换对象存储）
  createdAt: number
}
```

### 4.3 同步预留

所有本地数据操作收敛到 `stores/` 数据层，方法全部 async（list/put/delete）。
将来接 CloudBase 云同步时只替换该层实现，UI 不动。

## 5. 技术架构

- 框架：Vue 3 + Vite + TypeScript + Pinia
- 地图：Leaflet 1.9，GeoJSON 图层用 canvas renderer，保证动画流畅与海报导出
- 样式：Tailwind CSS（v4，@tailwindcss/vite 插件）
- 本地库：Dexie（IndexedDB）
- 海报导出：离屏 canvas 重绘点亮地图 + 统计卡，下载 PNG；不依赖 html2canvas 等截图库

## 6. 实施里程碑

- **M1 地图底座**：GeoJSON 下载/简化脚本、深色底图、缩放平移、城市边界图层与点亮填充
- **M2 数据与点亮**：内置数据集、Dexie store、Marker 三态、打卡弹窗、两级点亮规则
- **M3 看板与心愿**：统计看板、心愿清单（一键转打卡）
- **M4 日记与海报**：时间线视图、海报导出
- **M5 打磨**：点亮脉冲动画、移动端适配、搜索定位、全流程验收

## 7. 验收标准

完整用户旅程走查：打开地图 → 搜索/点击景点 → 打卡 → 城市点亮 → 查看统计看板 →
标记心愿 → 查看日记 → 导出海报。桌面与移动视口均需通过。
